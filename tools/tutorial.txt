Para descargar un juego (o DLC) utilizando **únicamente** los archivos `.lua` y `.manifest` (los que habitualmente te genera SteamTools o la comunidad) sin necesidad de tener la licencia comprada en tu cuenta de Steam, el DepotDownloader estándar no te servirá, ya que exige autenticación de cuenta y propiedad del juego.

Para lograrlo, debes utilizar una bifurcación (fork) modificada llamada **DepotDownloaderMod** (desarrollada por la comunidad de *SteamAutoCracks*), la cual permite realizar descargas anónimas inyectándole directamente las claves de desencriptado (*depot keys*) y los archivos de manifiesto locales de manera manual.

A continuación, tienes la guía paso a paso para hacerlo a mano o de forma automatizada mediante una interfaz gráfica.

---

## Método 1: Usando la herramienta gráfica "Steam Manifest Downloader" (Recomendado)

Si prefieres evitar escribir comandos en la consola, existe una aplicación de escritorio moderna llamada **Steam Manifest Downloader** (creada por *MCbabel*) que automatiza todo este proceso de forma visual utilizando `DepotDownloaderMod` por detrás:

1. Descarga el instalador desde el repositorio oficial de GitHub de [MCbabel/Steam-Manifest-Downloader](https://github.com/MCbabel/Steam-Manifest-Downloader).
2. Abre la aplicación y **sube el archivo `.lua**` de tu juego.
3. El programa extraerá automáticamente las claves de desencriptado (*depot keys*).
4. Selecciona los depósitos y el archivo `.manifest` correspondiente que tienes guardado.
5. Haz clic en **Download**; el programa se encargará de estructurar el comando y descargar los archivos limpios directamente a la carpeta que configures.

## Método 2: Método Manual (Paso a Paso)

Si quieres hacerlo tú mismo mediante la consola de comandos de Windows (CMD) o Linux, sigue estos pasos:

### Paso 1: Descargar DepotDownloaderMod

1. Ve al repositorio de [SteamAutoCracks/DepotDownloaderMod](https://github.com/SteamAutoCracks/DepotDownloaderMod) en GitHub.
2. Descarga la última versión compilada (usualmente dentro de una carpeta llamada `net9.0` o similar).

### Paso 2: Extraer las "Depot Keys" de tu archivo `.lua`

Para que DepotDownloaderMod pueda descargar los archivos sin pedirle permiso a Steam, necesita la clave criptográfica de cada depósito (*depot*). Estas claves están escritas dentro de tu archivo `.lua`:

1. Abre tu archivo `.lua` con cualquier editor de texto (como el Bloc de notas).
2. Busca líneas o estructuras que se parezcan a esto:
```lua
["depots"] = {
    ["123451"] = "abcdef1234567890abcdef1234567890abcdef1234567890abcdef12",
    ["123452"] = "9876543210fedcba9876543210fedcba9876543210fedcba98765432"
}

```


*(Donde `123451` es el ID del Depot y la cadena hexadecimal larga es su clave de descifrado).*
3. Crea un archivo de texto vacío en la carpeta de tu DepotDownloaderMod llamado **`claves.txt`**.
4. Escribe dentro las IDs y sus claves correspondientes utilizando el formato `id;clave` (una por línea). Por ejemplo:
```text
123451;abcdef1234567890abcdef1234567890abcdef1234567890abcdef12
123452;9876543210fedcba9876543210fedcba9876543210fedcba98765432

```


5. Guarda y cierra `claves.txt`.

### Paso 3: Organizar los Manifiestos

Asegúrate de copiar tu archivo `.manifest` (por ejemplo, `123451_987654321012345678.manifest`) dentro de la misma carpeta donde tienes el ejecutable de `DepotDownloaderMod.exe`.

### Paso 4: Ejecutar el comando de descarga

Abre la consola de comandos (CMD) en la carpeta del programa y ejecuta la siguiente estructura de comandos (reemplazando los datos por los tuyos):

```bash
DepotDownloaderMod.exe -app <AppID> -depot <DepotID> -manifest <ManifestID> -manifestfile <NombreDelArchivo.manifest> -depotkeys claves.txt

```

#### Ejemplo práctico:

Si quieres descargar el depot `457141` del juego `457140`:

```bash
.\DepotDownloaderMod.exe -app 1478500 -depot 1478501 -manifest 6520011635981099030 -manifestfile 1478501_6520011635981099030.manifest -depotkeys key.txt

```

> ⚠️ **Nota:** Al no especificar ningún parámetro de `-username` ni de `-password`, DepotDownloaderMod se conectará de manera **anónima** a los servidores de contenido de Valve. Usará tu manifiesto local para saber qué archivos pedir y tu archivo `claves.txt` para desencriptar el contenido descargado sobre la marcha, saltándose por completo la verificación de licencias de tu cuenta.
